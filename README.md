# Tech Doctor

অনলাইনের যেকোনো সমস্যার সমাধান: ওয়েবসাইট, সোশ্যাল মিডিয়া, ডিভাইস ও ডকুমেন্ট সার্ভিস।

## Features
- Responsive landing page (মোবাইল-ফ্রেন্ডলি)
- সার্ভিস, প্রাইসিং, রিভিউ ও FAQ সেকশন
- বাংলা ও ইংরেজি ফন্ট (Hind Siliguri, Poppins)
- Scroll animation ও mobile menu

## Getting Started
1. Repository clone করুন বা ZIP ডাউনলোড করুন।
2. `index.html` ফাইলটি ব্রাউজারে খুলুন।

## Customize
- `wa.me/8801XXXXXXXXX` ও ফোন নম্বর আপনার নম্বর দিয়ে বদলান।
- প্যাকেজের দাম ও রিভিউ আপনার তথ্য দিয়ে আপডেট করুন।
